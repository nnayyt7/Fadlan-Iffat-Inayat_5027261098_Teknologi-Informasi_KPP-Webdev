# SANGATTA — Kutai Timur

Landing page informatif tentang Sangatta, ibu kota Kabupaten Kutai Timur. Proyek ini menampilkan landmark Bukit Pelangi, ruang publik kota, Danau Polder Ilham Maulana, serta pilihan pesisir di sisi Selat Makassar.

## Teknologi

- HTML5 semantik
- CSS3 (Flexbox, Grid, CSS Variables, dan media queries)
- Google Fonts serta foto dokumentasi Sangatta dalam folder `image/`

## Struktur Proyek

```
Project new/
├── index.html
├── style.css
└── README.md
```
